# 本人授权

## 入口身份

`FEISHU_PI_ADMIN` 指定唯一使用者，可填写中文名、英文名或本机器人应用对应的 Open ID。姓名仅从本地资料缓存唯一匹配，英文名忽略大小写；未缓存或重名时填写 Open ID。启动不读取团队数据或查询通讯录，工程没有 admin/group 权限分组。

其他人的私聊、群聊消息和卡片点击不会进入 Agent。群聊仍要求本人 @机器人，避免普通讨论触发个人助理。

## 机器人与用户账号

回复、卡片和后台任务通知通过飞书 SDK 使用本机器人应用的 App ID/Secret。它们不依赖本机 lark-cli 登录账号。

AI 只能使用显式 `--as bot` 的飞书 CLI。省略身份、`--as user` 和 Meegle 用户态 CLI 均被身份通道拒绝，没有用户态启用开关。

- 私聊发送 `/login lark` 主动授权本人账号，令牌仅供预处理程序自动查询真实 @ 提及者的资料。
- `/login meegle` 仍可保存本人授权，但不会开放给 AI 的 CLI。
- CLI 子进程使用独立配置目录，不读取本机默认账号缓存。
- 普通 shell 不接触真实令牌；机器人 CLI 仅在实际启动时取得本应用凭证。
- 后台命令复用同一身份限制，代理保留到任务结束，再统一关闭。

AI 不调用 CLI 的 auth status/login/logout。用户使用 `/status`、`/login` 和 `/logout` 管理授权。

浏览器使用独立个人 profile。MCP 子进程不继承本工程密钥；需要的环境变量必须在 `.agent/mcp.json` 显式声明。

## 工具确认

确认卡只允许本人点击，一次性 token、消息来源和操作者均由服务端校验。超时、取消、服务重启后的旧卡均不会放行。deny 命中不发卡，不能通过点击覆盖禁止规则。
