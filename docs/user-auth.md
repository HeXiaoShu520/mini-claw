# 本人授权

## 入口身份

`FEISHU_PI_OWNER=ou_...` 指定唯一使用者。旧 `FEISHU_PI_ADMIN` 可作为迁移来源，已经没有 admin/group 权限分组。

其他人的私聊、群聊消息和卡片点击不会进入 Agent。群聊仍要求本人 @机器人，避免普通讨论触发个人助理。

## 机器人与用户账号

回复、卡片和后台任务通知通过飞书 SDK 使用本机器人应用的 App ID/Secret。它们不依赖本机 lark-cli 登录账号。

`MINICLAW_USER_CLI=0` 保留原来对用户令牌的限制：AI 只能使用显式 `--as bot` 的飞书 CLI；被 @ 人的资料查询仍由预处理程序按固定方式执行。

明确启用 `MINICLAW_USER_CLI=1` 后：

- 私聊发送 `/login lark` 或 `/login meegle` 主动授权本人账号。
- 省略身份或 `--as user` 使用本工程保存的本人令牌；`--as bot` 使用机器人应用凭证。
- 子进程使用独立 CLI 配置目录，不读取本机默认账号缓存。
- 没有有效令牌时拒绝，推送授权引导；缺少 scope 时发起增量授权。
- 普通 shell 不接触真实令牌。只有受控 CLI 子进程在实际启动时取得所需凭证。
- 后台命令复用同一身份通道，代理保留到任务结束，再统一关闭。

AI 不调用 CLI 的 auth status/login/logout。用户使用 `/status`、`/login` 和 `/logout` 管理授权。

浏览器使用独立个人 profile。MCP 子进程不继承本工程密钥；需要的环境变量必须在 `.agent/mcp.json` 显式声明。

## 工具确认

确认卡只允许本人点击，一次性 token、消息来源和操作者均由服务端校验。超时、取消、服务重启后的旧卡均不会放行。deny 命中不发卡，不能通过点击覆盖禁止规则。
